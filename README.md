# iCalc — калькулятор закупок для кондитера

Офлайн веб-приложение (PWA) для iPhone. Без сервера и без сборки: обычные статические файлы.
Данные хранятся только на телефоне (localStorage).

## Как пользоваться

1. **Ингредиенты** — для каждого: единица (г / мл / шт), одна или несколько фасовок в магазине
   (размер, название, цена), магазин, пометка «скоропортящийся» и сколько есть дома.
   Для штучного (яйца) можно указать вес штуки — тогда в рецептах их можно писать в граммах.
   Кнопка «Инвентаризация» — быстро вписать запасы списком.
2. **Рецепты** — состав на одну партию, в г/кг/мл/л/шт. Дополнительно:
   - **полуфабрикат** (крем, бисквит) — можно вставлять в другие рецепты, в партиях или граммах (если указан выход);
   - **Ø формы** — чтобы в плане пересчитать рецепт под другой диаметр (по площади);
   - **потери, %** — запас ко всем ингредиентам рецепта;
   - себестоимость партии считается автоматически по ценам фасовок.
3. **План** — заказ или день выпечки, с названием и датой. Планов может быть несколько,
   режим «Все» собирает общий список покупок. Список покупок:
   - самая выгодная комбинация фасовок (по цене, без цен — с наименьшим остатком);
   - разбит по магазинам, скоропорт помечен датой, к которой он нужен;
   - мелкие нехватки ниже порога из настроек не покупаются;
   - «Купила» — можно поправить, что купила на самом деле, и добавить в запасы;
   - «Испекла…» у рецепта — списать часть партий; «Испекла всё» — весь план.
4. **Ещё** — языки, валюта, порог докупки, резервная копия, пример данных.

### Языки

Страница «Ещё → Языки»: русский или польский отдельно для интерфейса, названий выпечки,
названий ингредиентов, единиц измерения, типов упаковок и текста списка покупок для отправки.
У ингредиентов и рецептов по два названия (достаточно одного; если перевода нет — показывается
другое). Типы упаковок — встроенный двуязычный список (или своя упаковка с названиями).
Частые продукты переводятся автоматически по словарю в `i18n.js` (`GLOSSARY`).

## Как установить на iPhone

Service worker (офлайн-режим) работает только по HTTPS, поэтому файлы надо выложить на любой
бесплатный статический хостинг. Проще всего:

- **Netlify Drop**: открыть https://app.netlify.com/drop и перетащить папку проекта
  (без `.claude` и `README.md` — можно и с ними). Получится адрес вида `https://xxx.netlify.app`.
- или **GitHub Pages**: залить файлы в репозиторий → Settings → Pages.

Затем на iPhone: открыть адрес в **Safari** → «Поделиться» → **«На экран “Домой”»**.
После первого открытия приложение работает без интернета.

## Обновление приложения

После изменения файлов **обязательно** увеличьте `CACHE` в `sw.js` (например `icalc-v5`) и выложите заново.
Телефон скачает новую версию целиком при запуске с интернетом и сразу перезагрузит приложение.
Данные при обновлении не теряются.

## Файлы

- `index.html`, `styles.css`, `app.js` — само приложение
- `i18n.js` — тексты интерфейса на русском и польском (язык переключается в «Ещё»)
- `sw.js` — офлайн-кэш
- `manifest.webmanifest`, `icons/` — иконка и установка на экран «Домой»
