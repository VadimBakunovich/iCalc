# iCalc — калькулятор закупок для кондитера

Офлайн веб-приложение (PWA) для iPhone. Без сервера и без сборки: обычные статические файлы.
Данные хранятся только на телефоне (localStorage).

## Как пользоваться

1. **Ингредиенты** — для каждого: единица (г / мл / шт), сколько в упаковке, как называется упаковка
   (пачка, лоток…), цена (необязательно) и сколько есть дома.
2. **Рецепты** — список ингредиентов на одну партию (один торт, противень печенья).
3. **План** — выбрать рецепты и количество партий. Ниже сразу появляется список покупок:
   сколько упаковок купить с учётом запасов дома, сколько останется, примерная стоимость.
   - тап по строке — отметить купленное;
   - «Отправить список» — в Заметки/мессенджер;
   - «Купила — добавить в запасы» — купленные упаковки прибавляются к запасам дома;
   - «Испекла — списать из запасов» — расход по плану вычитается из запасов, план очищается.
4. **Ещё** — резервная копия (сохранить/восстановить файл), валюта, пример данных.

## Как установить на iPhone

Service worker (офлайн-режим) работает только по HTTPS, поэтому файлы надо выложить на любой
бесплатный статический хостинг. Проще всего:

- **Netlify Drop**: открыть https://app.netlify.com/drop и перетащить папку проекта
  (без `.claude` и `README.md` — можно и с ними). Получится адрес вида `https://xxx.netlify.app`.
- или **GitHub Pages**: залить файлы в репозиторий → Settings → Pages.

Затем на iPhone: открыть адрес в **Safari** → «Поделиться» → **«На экран “Домой”»**.
После первого открытия приложение работает без интернета.

## Обновление приложения

После изменения файлов увеличьте `CACHE` в `sw.js` (например `icalc-v2`) и выложите заново.
На телефоне новая версия подтянется со второго запуска (нужен интернет в момент запуска).
Данные при обновлении не теряются.

## Файлы

- `index.html`, `styles.css`, `app.js` — само приложение
- `sw.js` — офлайн-кэш
- `manifest.webmanifest`, `icons/` — иконка и установка на экран «Домой»
